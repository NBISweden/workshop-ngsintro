5 Chunk attributes

Properties and behaviour of code chunks can be controlled using chunk attributes. This is specified as comment sign of the language and pipe followed by key: value. So for example, in R: #| eval: false.

In this example, the R source code and results are hidden but the code is evaluated.

```{r}
#| eval: true
#| echo: false
#| results: hide
Sys.Date()
```

A code chunk can be given a code filename using the chunk attribute filename.

```{r}
#| filename: R code
Sys.Date()
```

Enable line numbers using code-line-numbers: true.

```{r}
#| code-line-numbers: true
Sys.Date()
sessionInfo()
```

An advanced example showing bash code generated from R.

```{r}
#| attr-output: "filename='bash'"
#| class-output: bash
#| echo: false
d <- "custom"
cat(paste("mkdir​", d))
```

Code chunk attributes are documented here.

15 Shortcodes

Shortcodes are sort of like quarto functions.

Two important shortcodes are meta and var. meta allows to read metadata from the yaml block in the current page or from _quarto.yml. Here are a few examples:

16 Accordions

Accordion support is provided through the accordion extension.

Accordion contents can be defined in the YAML header as shown below.

accordion:
  - ac-1:
    - header: "**This is a header**"
      body: "This is **bold** and *italic* text"

and then called in the body using the shortcode.

{{< accordion ac-1 >}}
This is bold and italic text

Alternatively, an accordion can be defined inline as shown below.

{{< accordion label="my-accordion" header="Click to expand" body="This is the content of the accordion." >}}
This is the content of the accordion.

Multiple inline items are defined using JSON.

{{< accordion label="inline-multi" items='[
  { "header": "Inline Item 1", "body": "Content for inline item 1." },
  { "header": "Inline Item 2", "body": "Content for inline item 2." }
]' >}}
Content for inline item 1.
Content for inline item 2.
